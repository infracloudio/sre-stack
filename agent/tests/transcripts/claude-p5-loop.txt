`★ Insight ─────────────────────────────────────`
- `lint` runs whole-repo gates in sequence: secrets scan → protected paths → shellcheck → yamllint → helm lint. Missing tools degrade to warnings, so exit 0 does not mean every gate ran.
- Chart lints twice (absolute path + relative) because `lint` and `lint-changed` targets each invoke helm lint on their own resolved path.
