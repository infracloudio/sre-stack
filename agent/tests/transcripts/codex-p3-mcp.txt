As of **September 3, 2026**, AKS support is:

- **Full GA support:** Kubernetes **1.34, 1.35, and 1.36**
- **Reduced platform support:** **1.33**, until Kubernetes 1.37 reaches GA
- **Long-Term Support (LTS):** **1.31 through 1.36**, when AKS LTS is enabled
- **Preview:** Kubernetes **1.37** is scheduled for preview during September 2026; regional availability may vary

Exact patch releases vary by region and subscription:

```bash
az aks get-versions --location <region> --output table
```

Source: [Microsoft Learn — Supported Kubernetes versions in AKS](https://learn.microsoft.com/en-us/azure/aks/supported-kubernetes-versions#aks-kubernetes-release-calendar-and-upcoming-versions). Microsoft states that AKS fully supports the latest three GA minor versions (`N`, `N-1`, and `N-2`).
