## Patches
Per minor: any number of patches tracked at [releases.aks.azure.com](https://releases.aks.azure.com/). Max two patches retained per minor as new ones ship; oldest deprecated. Use latest patch.

## LTS
Optional long-term support extends EOL ~12 months (e.g. 1.34 LTS → Nov 2027). Must be explicitly enabled.

## kubectl skew
±1 minor vs kube-apiserver, per upstream Kubernetes policy.

Note: Azure Linux 2.0 node image EOL Nov 30, 2025; removed Mar 31, 2026. Migrate to Azure Linux 3.0.
