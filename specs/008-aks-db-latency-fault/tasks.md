## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependencies)
- **[Story]**: Which user story this task belongs to (US1 start, US2 revert, US3 status, US4 guide)

**Terms used below**:

- **Finding N**: a numbered entry in `research.md`, recorded from a live run on the cluster.
- **Quickstart step N**: a numbered step in `quickstart.md`.
- **Deviation D1, D2, …**: a numbered row in the table of departures from an approved artifact, kept at the end of this file; D1 is the first row.
