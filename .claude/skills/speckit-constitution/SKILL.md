# Speckit Constitution Skill

## Input and shared contract

Consider `$ARGUMENTS`. Before any action read `agent/spec-kit/rules.md` and
`agent/spec-kit/story-cost.md`, plus the constitution and AGENTS.md. Apply the
shared compact, research, section approval, convergence and hook rules in full.
Read the configured before/after hooks for constitution; actually execute mandatory
hooks and wait. No printed invocation substitutes for execution.

## Constitution

Read .specify/memory/constitution.md and the proposed amendment. Resolve
missing amendment intent with the user. Follow constitution governance and
independent approval; do not silently redefine existing principles. Propose
specific wording, semantic version rationale and a sync impact report; update
the amended date. Preserve research VIII, incremental authoring IX and bounded
convergence X unless an explicitly approved scope authorizes their change.
Trace affected rules into agent/spec-kit project-owned sources and framework
docs, then regenerate through the CLI instead of editing generated commands.
Report changes, propagation gaps and required approval.

Report only decisions, changed paths, checks, blockers and the next step.
